# Jarvis — новые настройки

## Автоматические обновления

Лаунчер проверяет GitHub Releases примерно через секунду после запуска. Если
версия новее текущей и в релизе есть ZIP-файл, пользователь увидит уведомление.
После согласия архив скачивается, Jarvis закрывается, файлы заменяются и
программа запускается снова. `jarvis.db` и `.env` при обновлении сохраняются.
В публичный архив секреты не входят: задавайте ключи через переменные
окружения или серверный backend.

Перед первой сборкой замените `YOUR_GITHUB_NAME/Jarvis` в
`build_windows.bat` и в начале `launcher.py` на реальный `владелец/репозиторий`.
Каждое обновление выпускайте новым тегом вида `v2.6.4`, а в релиз прикладывайте
файл `dist\Jarvis-windows.zip` (его создаёт build-скрипт).

В лаунчере на странице **Настройки** добавлены:

- поле **Ключевое слово** — по умолчанию `Джарвис`; после сохранения ассистент
  реагирует на указанное слово;
- список голосов для сгенерированных ответов: Джарвис, Мита, Мариарти, Рик,
  Морти и Губка Боб;
- флажок **Использовать характер выбранного голоса** — меняет стиль ответов
  под персонажа; без флажка все голоса отвечают стандартно;
- предупреждение о том, что дополнительные голоса доступны только онлайн.

Настройки сохраняются в Windows `QSettings` и передаются голосовому модулю
только при следующем запуске прослушивания.

## `.env`

Для локального базового голоса Джарвиса новый ключ не нужен.

Для голосов Миты, Мариарти, Рика, Морти и Губки Боба нужен уже используемый
ключ Fish Audio:

```env
FISH_AUDIO_API_KEY=ваш_ключ
```

Если ключ уже настроен в текущей сборке, добавлять ничего не требуется:
ID выбранного голоса лаунчер передаст автоматически. `FISH_AUDIO_REFERENCE_ID`
можно оставить как есть — он используется для базового голоса Джарвиса и
обратной совместимости. Не добавляйте секреты в архив или публичный репозиторий.

Для естественных реплик после действий и характеров также должен быть настроен
один из используемых AI-ключей (`AI_API_KEY`, `DEEPSEEK_API_KEY` или
`MISTRAL_API_KEY`). Без AI-ключа действие всё равно выполнится, но ответ будет
резервным техническим сообщением.
